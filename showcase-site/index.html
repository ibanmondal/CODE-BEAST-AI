Questions & Answers

Frequently Asked Questions

Technical explanations for hackathon judges, academic committees, and engineers.

How does Code Beast evaluate code without executing untrusted scripts?
Code Beast AI uses Tree-Sitter Abstract Syntax Tree (AST) parsing. It compiles source code into structural grammar trees in C-speed memory without ever executing arbitrary scripts, guaranteeing 100% security sandbox isolation.
Why is the memory footprint only 65MB RAM?
Traditional neural code analyzers load heavy PyTorch and HuggingFace Transformers weights (950MB+), which crash free-tier cloud containers (512MB RAM). We replaced the neural models with a custom C-binding Tree-Sitter AST parser and lightweight token Jaccard hash matching, lowering memory to 65MB.
How does ConsJudge™ prevent AI hallucination?
ConsJudge runs dual concurrent evaluation passes across different high-capacity foundation models (Groq LLaMA 3.3 70B and NaraRouter Claude/GPT-4o). It computes the inter-judge variance margin; if variance is ≤ 2.0 points, it issues a verified High Confidence Badge.
Can I evaluate batches of 50 or 100 repositories?
Yes! Via the /upload endpoint or Bulk Analysis tab, you can submit batches of any size. The sliding-window orchestrator slices them into chunks of 5 and processes them sequentially, streaming live status via WebSockets.
Where are the official certificates stored?
All evaluations are saved to the persistent production database. Certificates can be viewed anytime in the Trophy Hall (/judges) and exported to crisp 300 DPI A4 Landscape PDFs.
