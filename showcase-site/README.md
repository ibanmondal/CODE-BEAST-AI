## 🚀 How to Host This Website in 30 Seconds

### Option 1: Host on Vercel (Recommended — Free & Instant)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Choose **Deploy Other Directory** or drag-and-drop this `showcase-site` folder directly.
3. Click **Deploy**. Your showcase site will be live instantly with a free `https://<your-project>.vercel.app` domain!

### Option 2: Host on Netlify (Free Drag-and-Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `showcase-site` folder into your browser window.
3. Your site goes live immediately with a free `.netlify.app` URL!

### Option 3: Host on GitHub Pages
1. Push this folder to a GitHub repository (e.g. `codebeast-showcase` or branch `gh-pages`).
2. Go to **Settings** ➔ **Pages** ➔ Set Branch to `main` and folder to `/`.
3. Your site is live at `https://<username>.github.io/<repo-name>`.
